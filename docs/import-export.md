# 导出与导入

设置页提供「导出」「导入」两个按钮。笔记卡片不再响应左划删除；可通过编辑页删除菜单或长按多选后的删除按钮移入回收站。

## 导出

点击「导出」并选择一个文件夹，一次生成带相同时间及随机后缀的两个文件：

- `ColorMemo-日期时间-后缀.json`：完整笔记快照，含可编辑白板、原始附件、颜色、置顶、归档、回收站、删除标记、提醒和修订信息。
- `ColorMemo-日期时间-后缀-Markdown.zip`：普通与归档笔记的 Markdown、附件及白板 SVG，同时在 ZIP 根目录附带同一快照的 `colormemo.json`。

两个文件使用同一次读取的快照。先在应用缓存中完成 ZIP，再创建目标文件，避免转换失败时留下半份导出。既有导出不被覆盖；写入失败时尝试清理本次创建的文件，存储提供商拒绝删除时会提示可能存在不完整文件。

系统文件夹选择器在 Android 11 及以上不允许直接选择存储根目录或 Download 根目录，可选择或新建其中的子文件夹。导出不要求整个存储空间权限，也不保存长期文件夹授权。

## 导入彩笺文件

点击「导入」，选择 JSON 或 Markdown ZIP。文件按内容识别；旧版 JSON 仍可使用，支持 UTF-8 BOM。导入先校验，再与最新本地笔记合并，保留并发修改的冲突副本，不清空数据库。相同 JSON 或新版 ZIP 重复导入不会生成重复笔记。

新版 ZIP 以 `colormemo.json` 为准，完整保留白板编辑能力和笔记状态，不再把其中的 Markdown 作为另一批笔记重复导入。单层或多层外包目录也可识别。若手工修改 ZIP 中的 Markdown，原生 JSON 中的内容仍优先；没有原生 JSON 的 ZIP 按下节的通用 Markdown 方式迁入。原生 JSON 损坏或版本不支持时停止导入。

JSON 与 ZIP 都是明文文件，不含同步密码、恢复密钥、MCP 令牌、本机 AI 授权或未提交的编辑草稿。远端的加密同步文件需通过应用内同步读取，不能直接作为 JSON 导入。

## 从其他应用迁移

将其他应用导出的 Markdown 文件及其图片、附件放在同一个 ZIP 中后导入。支持：

- ZIP 子目录内的 `.md`、`.markdown`、`.mdown`、`.mkd`，扩展名不区分大小写；UTF-8、BOM、中文文件名和 CRLF 换行。
- 标题优先取 YAML front matter 的简单 `title` 字段，其次为开头的一级标题，最后为文件名。提升为笔记标题的开头一级标题从正文中移除；含图片或链接的一级标题仍保留在正文，以免丢失引用。YAML、标签等原始字段继续留在正文。
- 常见 `created`、`created_at`、`created_time`、`date` 和对应更新时间字段中的 ISO 时间及秒/毫秒时间戳；无时区的 ISO 时间按 UTC 解释。没有可识别时间时使用 ZIP 中的文件时间。
- 常规 Markdown 图片、文件链接及引用式链接；相对目录、空格的百分号编码、括号及中文路径。附件保存原始字节，链接转换为彩笺内部附件路径；引用式附件在使用处展开为内联链接，保留标签与标题。重复引用只保存一份附件。
- Obsidian 的 `![[图片.png]]`、`![[图片.png|宽度]]` 和 `[[文件.pdf|说明]]`；优先匹配相对路径或库内路径，只有唯一候选时才按文件名匹配。
- 旧版彩笺的 `notes/`、`archive/` ZIP 布局。归档状态保留；旧版白板 SVG 保留为附件，不会还原可编辑笔画。

通用 Markdown 每个文件新建一条笔记，同名文件不会互相覆盖；再次迁移同一份通用 ZIP 会再次新建。正文中的代码、任务清单、表格、图表和公式原样保留；导入过程不运行脚本或下载网络图片。其他应用的笔记本、标签、专有语法和跨笔记跳转没有对应映射，原有内容及链接保留为文本。图片能否直接预览取决于 Android 支持的格式。文件附件可从正文链接或文件卡片打开，旧版白板 SVG 也有独立卡片入口。

缺失或存在多个候选的本地附件不被猜测替换：保留原链接，并报告未找到文件的链接数量。macOS 资源分叉和隐藏配置目录不作为笔记迁入。其他应用的专有 JSON 数据结构不在通用 JSON 导入范围内。

## 校验与上限

输入文件最多 64 MiB，ZIP 声明的解压总量最多 128 MiB、100,000 个条目。读取时仍检查实际大小与 CRC；不将 ZIP 路径解压到文件系统，拒绝绝对路径、越界路径和归一化后重名的条目。

导入结果沿用彩笺已有上限：标题 500 字符、单条正文 100,000 字符、单个附件 5 MiB、每条附件合计 8 MiB / 20 个、笔记 10,000 条。导入与本地笔记合并后的完整 JSON 也必须在 16 MiB 以内。超限、文本编码错误或损坏的被引用文件都会使本次导入失败，不写入其中已解析的笔记。

源码、Lint 和单元测试使用 `python3 tools/verify-termux.py` 验证，不在本机构建 APK。系统文件选择器、实际存储提供商写入与失败清理需要在 Android 设备上验收。

实现依据：[Android Storage Access Framework](https://developer.android.com/training/data-storage/shared/documents-files)、[DocumentsContract.createDocument](https://developer.android.com/reference/android/provider/DocumentsContract)、[CommonMark 链接](https://spec.commonmark.org/0.31.2/#links)。
