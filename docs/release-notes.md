# 彩笺 · ColorMemo 0.2.5

支持 Android 8.0 及以上版本，可覆盖安装旧版本升级。

- 恢复密钥仅在首次配置时提供输入、生成和复制，并要求先备份再保存；保存后只显示已配置状态，关闭再开启同步也不会恢复密钥操作入口。
- 首次配置中关闭同步后保存，不会将尚未确认备份的密钥保存为已配置密钥。
- 已配置恢复密钥的设备重新启用同步时，不再重复要求确认备份。

升级后，已有恢复密钥继续用于同步，设置页不再提供显示、复制、生成或更换入口。在新设备配置时，请使用首次配置时保存在应用外的密钥备份。

下载 `ColorMemo-v0.2.5.apk` 安装。APK 由 GitHub Actions 构建，使用与 MDTerm Release 相同的签名证书。应用包名为 `dev.colormemo.app`，可与 MDTerm 同时安装。

```
4bea1b63b90233d46ed951d66bae2927440c595323234556da7d2038aec25e89
```

**使用附件或新笔型前，请先将所有同步设备升级至 v0.2.4 或更新版本。** 旧客户端会拒绝包含新字段的快照，不会静默丢弃附件或改变笔型。从 v0.2.0～v0.2.4 升级可继续使用原有加密同步位置和恢复密钥。

从更早的明文同步版本升级时，先完成旧设备同步并保留备份，再停用旧版同步、升级所有设备，改用新的空 WebDAV 目录或 S3/R2 对象前缀和同一份恢复密钥。应用不会自动转换或删除旧远端文件。

同步默认关闭，无需注册账号。附件单个最多 5 MiB，每条笔记合计最多 8 MiB、20 个；附件编码后的内容计入现有的 16 MiB 快照上限。恢复密钥不包含在备份中；密钥及所有已配置设备均丢失后，远端数据无法解密。本机数据库、私有附件文件与手动 JSON/Markdown 导出仍为明文。Android 省电策略可能延迟提醒和后台同步。

首次使用可先创建笔记并设置提醒，再按 [README](https://github.com/giturass/ColorMemo#配置同步) 配置云端同步。已有备份建议先保留副本。
