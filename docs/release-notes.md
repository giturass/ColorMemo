# 彩笺 · ColorMemo 0.2.11

支持 Android 8.0 及以上版本，可覆盖安装旧版本升级。

- “细签字笔”更名为“签字笔”。画笔提供 24 种预设颜色及自定义 RGB 颜色；图形和辅助工具统一跟随画笔颜色，无需单独设置。
- 新增曲箭头、双箭头、正方形、梯形、六边形、圆柱、圆锥、立方体、球体、角和坐标系，共提供 18 种图形。正方形、圆形、立方体和球体保持等宽高比例。
- 新增可调圆规：移动圆心、拖动半径手柄或使用滑块调整大小，再点击“画圆”。新增可调量角器：移动位置、旋转基线、调整测量边，实时显示角度，并可绘制对应的角。
- 支持开关辅助线，显示网格、绘制时的水平与垂直参考线及图形边界。辅助线、圆规和量角器仅在编辑时显示，画出的圆和角作为普通笔迹保存。
- 支持向白板插入多行文字、拖动位置、编辑内容、调整字号和删除。文字颜色跟随画笔，支持撤销、重做、预览、加密同步、JSON 备份及 SVG 导出。
- 白板帮助及[工具说明](https://github.com/giturass/ColorMemo/blob/main/docs/whiteboard.md)同步更新。

升级后，已有恢复密钥继续用于同步，设置页不再提供显示、复制、生成或更换入口。在新设备配置时，请使用首次配置时保存在应用外的密钥备份。

下载 `ColorMemo-v0.2.11.apk` 安装。APK 由 GitHub Actions 构建，使用与 MDTerm Release 相同的签名证书。应用包名为 `dev.colormemo.app`，可与 MDTerm 同时安装。

**使用白板文字同步前，请先将所有同步设备升级至 v0.2.11 或更新版本。** 旧客户端会拒绝包含白板文字图层的同步快照或 JSON 备份，避免丢失内容。白板插图要求所有同步设备至少升级至 v0.2.8。已有便签文字、Markdown 图片和白板笔迹可直接读取。从 v0.2.0 及更新版本升级可继续使用原有加密同步位置和恢复密钥。

从更早的明文同步版本升级时，先完成旧设备同步并保留备份，再停用旧版同步、升级所有设备，改用新的空 WebDAV 目录或 S3/R2 对象前缀和同一份恢复密钥。应用不会自动转换或删除旧远端文件。

同步默认关闭，无需注册账号。附件单个最多 5 MiB，每条笔记合计最多 8 MiB、20 个，每块白板最多 20 个图片图层；附件编码后的内容计入现有的 16 MiB 快照上限。便签远程图片在预览时访问来源服务器，图片内容由原地址提供。恢复密钥不包含在备份中；密钥及所有已配置设备均丢失后，远端数据无法解密。本机数据库、私有附件文件与手动 JSON/Markdown 导出仍为明文。Android 省电策略可能延迟提醒和后台同步。

首次使用可先创建笔记并设置提醒，再按 [README](https://github.com/giturass/ColorMemo#配置同步) 配置云端同步。已有备份建议先保留副本。
