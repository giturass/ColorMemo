# 彩笺 · ColorMemo 0.2.10

支持 Android 8.0 及以上版本，可覆盖安装旧版本升级。

- 修复橡皮触碰局部却删除整条笔画或整个图形的问题：现在只截断扫过的局部笔迹，保留其余部分和图片，支持快速划动和缩放后的擦除。
- 图形按钮仅显示当前图形符号，菜单顶部可直接选择颜色，换色后继续绘制图形。
- 局部擦除保留笔型、颜色和粗细，支持撤销、重做、保存、同步与 SVG 导出；擦除后的片段超出容量时保留原笔迹并提示。白板帮助同步更新。

升级后，已有恢复密钥继续用于同步，设置页不再提供显示、复制、生成或更换入口。在新设备配置时，请使用首次配置时保存在应用外的密钥备份。

下载 `ColorMemo-v0.2.10.apk` 安装。APK 由 GitHub Actions 构建，使用与 MDTerm Release 相同的签名证书。应用包名为 `dev.colormemo.app`，可与 MDTerm 同时安装。

**使用白板插图同步前，请先将所有同步设备升级至 v0.2.8 或更新版本。** 旧客户端会拒绝包含图片图层的同步快照或备份，避免丢失图片。已有文字、Markdown 图片和白板笔迹可直接读取。从 v0.2.0～v0.2.7 升级可继续使用原有加密同步位置和恢复密钥。

从更早的明文同步版本升级时，先完成旧设备同步并保留备份，再停用旧版同步、升级所有设备，改用新的空 WebDAV 目录或 S3/R2 对象前缀和同一份恢复密钥。应用不会自动转换或删除旧远端文件。

同步默认关闭，无需注册账号。附件单个最多 5 MiB，每条笔记合计最多 8 MiB、20 个，每块白板最多 20 个图片图层；附件编码后的内容计入现有的 16 MiB 快照上限。便签远程图片在预览时访问来源服务器，图片内容由原地址提供。恢复密钥不包含在备份中；密钥及所有已配置设备均丢失后，远端数据无法解密。本机数据库、私有附件文件与手动 JSON/Markdown 导出仍为明文。Android 省电策略可能延迟提醒和后台同步。

首次使用可先创建笔记并设置提醒，再按 [README](https://github.com/giturass/ColorMemo#配置同步) 配置云端同步。已有备份建议先保留副本。
