# 彩笺 · ColorMemo 0.2.0

支持 Android 8.0 及以上版本，可覆盖安装旧版本升级。

- 支持白板笔记，可手写、涂鸦、擦除和继续编辑，随笔记同步并导出为 SVG。
- 云同步强制端到端加密：文字、白板及修订信息均使用 AES-256-GCM 在设备上加密，各设备共享一份恢复密钥。

下载 `ColorMemo-v0.2.0.apk` 安装。APK 由 GitHub Actions 构建，使用与 MDTerm Release 相同的签名证书。应用包名为 `dev.colormemo.app`，可与 MDTerm 同时安装。

签名证书 SHA-256：

```
4bea1b63b90233d46ed951d66bae2927440c595323234556da7d2038aec25e89
```

**同步协议不兼容旧版明文文件。** 升级前先让旧设备完成同步并保留备份，然后停止旧版同步。升级所有设备后，选择新的空 WebDAV 目录或 S3/R2 对象前缀，生成并安全备份恢复密钥；在其他设备配置同一位置和密钥，再从已有本地笔记重新上传。应用不会自动转换或删除旧远端文件，旧明文及服务端历史版本需自行管理。

同步默认关闭，无需注册账号。加密前的快照最多 16 MiB，支持文字和白板笔记。恢复密钥不包含在备份中；密钥及所有已配置设备均丢失后，远端数据无法解密。本机数据库与手动 JSON/Markdown 导出仍为明文。Android 省电策略可能延迟提醒和后台同步。

首次使用可先创建笔记并设置提醒，再按 [README](https://github.com/giturass/ColorMemo#配置同步) 配置云端同步。已有备份建议先保留副本。
