# 彩笺 · ColorMemo 0.2.3

支持 Android 8.0 及以上版本，可覆盖安装旧版本升级。

- 自动同步支持间隔设置，默认 15 分钟，可选 15／30 分钟及 1／3／6／12／24 小时；更改后更新后台任务。
- 优化恢复密钥操作：复制按钮显示复制反馈，重新生成收进更多菜单并增加确认，避免误触替换密钥。
- 更新应用图标，采用新的便签与铅笔图案，并适配圆形图标和主题图标。
- 便签与白板分类独立显示，白板不再出现在便签页；侧栏及相关界面文案统一为“便签”，分类数量分别统计。
- Markdown 工具栏新增下划线和删除线，预览支持下划线排版。
- 编辑页左下角颜色旁新增附件按钮，可添加、打开和移除文件；完整附件随笔记加密同步，JSON 备份和 Markdown ZIP 导出也保留文件内容。
- 白板画笔和橡皮改为图标，移除移动按钮，保留双指移动、缩放和查看全图；新增细签字笔、水彩笔、马克笔，以及八档圆点粗细。笔型和笔触效果保留到同步、卡片预览与 SVG 导出。
- 主界面卡片隐藏三点菜单和修改时间，支持长按多选、批量操作及左划移入回收站；最后修改时间移至编辑页底部中间的三点菜单。

下载 `ColorMemo-v0.2.3.apk` 安装。APK 由 GitHub Actions 构建，使用与 MDTerm Release 相同的签名证书。应用包名为 `dev.colormemo.app`，可与 MDTerm 同时安装。

**使用附件或新笔型前，请先将所有同步设备升级至 v0.2.3。** 旧客户端会拒绝包含新字段的快照，不会静默丢弃附件或改变笔型。从 v0.2.0／v0.2.1 升级可继续使用原有加密同步位置和恢复密钥。

从更早的明文同步版本升级时，先完成旧设备同步并保留备份，再停用旧版同步、升级所有设备，改用新的空 WebDAV 目录或 S3/R2 对象前缀和同一份恢复密钥。应用不会自动转换或删除旧远端文件。

同步默认关闭，无需注册账号。附件单个最多 5 MiB，每条笔记合计最多 8 MiB、20 个；附件编码后的内容计入现有的 16 MiB 快照上限。恢复密钥不包含在备份中；密钥及所有已配置设备均丢失后，远端数据无法解密。本机数据库、私有附件文件与手动 JSON/Markdown 导出仍为明文。Android 省电策略可能延迟提醒和后台同步。

首次使用可先创建笔记并设置提醒，再按 [README](https://github.com/giturass/ColorMemo#配置同步) 配置云端同步。已有备份建议先保留副本。
