# 彩笺 · ColorMemo 0.2.19

支持 Android 8.0 及以上版本，可覆盖安装旧版本升级。

- 新增「本地 AI 服务」：Codex 等同一台设备上的 AI 客户端可通过 MCP 创建、读取、搜索、编辑和管理已授权的笔记。服务默认关闭，开启后仅监听本机，使用每次更新的临时访问令牌；设置页和通知均可停止。
- 编辑页底部三点按钮右侧新增「AI」可见性按钮。已有笔记和手动新建笔记默认不可见，已保存笔记的授权或隐藏立即生效；授权仅保存在当前设备，不随同步或备份传递。AI 创建的便签自动授权。
- AI 修改须匹配笔记当前版本，避免覆盖并发编辑；隐藏笔记不会出现在 AI 的列表、搜索或直接访问中。数据库升级保留原有笔记，新增的授权表默认为空。
- 为适应窄屏，将「设置提醒」移入编辑页底部三点菜单。

配置步骤和权限范围见 [本地 AI 笔记服务](https://github.com/giturass/ColorMemo/blob/v0.2.19/docs/ai-mcp.md)。白板暂支持读取、修改标题与说明和管理，不支持通过 MCP 绘制或传输附件文件。

升级后，已有恢复密钥继续用于同步，设置页不再提供显示、复制、生成或更换入口。在新设备配置时，请使用首次配置时保存在应用外的密钥备份。

下载 `ColorMemo-v0.2.19.apk` 安装。APK 由 GitHub Actions 构建，使用与 MDTerm Release 相同的签名证书。应用包名为 `dev.colormemo.app`，可与 MDTerm 同时安装。

**使用白板新纵向区域或裁剪前，请先将所有同步设备升级至 v0.2.13 或更新版本。** 旧客户端会拒绝纵坐标超出 2000 或含裁剪记录的数据，避免丢失内容。白板文字至少需要 v0.2.11，白板插图至少需要 v0.2.8。已有便签文字、Markdown 图片和白板内容可直接读取。从 v0.2.0 及更新版本升级可继续使用原有加密同步位置和恢复密钥。

从更早的明文同步版本升级时，先完成旧设备同步并保留备份，再停用旧版同步、升级所有设备，改用新的空 WebDAV 目录或 S3/R2 对象前缀和同一份恢复密钥。应用不会自动转换或删除旧远端文件。

同步默认关闭，无需注册账号。附件单个最多 5 MiB，每条笔记合计最多 8 MiB、20 个，每块白板最多 20 个图片图层；附件编码后的内容计入现有的 16 MiB 快照上限。便签远程图片在预览时访问来源服务器，图片内容由原地址提供。恢复密钥不包含在备份中；密钥及所有已配置设备均丢失后，远端数据无法解密。本机数据库、私有附件文件与手动 JSON/Markdown 导出仍为明文。Android 省电策略可能延迟提醒和后台同步。

首次使用可先创建笔记并设置提醒，再按 [README](https://github.com/giturass/ColorMemo#配置同步) 配置云端同步。已有备份建议先保留副本。
